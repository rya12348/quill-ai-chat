How this runs

  1. The game lives in its own tab or window. Not in a frame, not through a proxy page: the party asks for a human verification that is tied to the game's own address, so anything that re-serves the page from another address cannot pass it. This console is separate from the game on purpose.
  2. The bot is a userscript in that tab. Install or update it from 127.0.0.1:8081/puffer-bot.user.js, then reload the game tab. This page and the pack server keep working while it plays.
  3. Nothing here is proxied. The only network the bot uses is this machine: the pack and model on 127.0.0.1:5201, plus the game tab's own connection.
